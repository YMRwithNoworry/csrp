# 自然刷怪数量调整

默认寄生虫刷怪权重从 3.0 提高到 6.0；维度内数量上限从 50＋每名玩家 10 提高到 100＋每名玩家 20（单人由 60 提高到 120）。

保留原有进化阶段与普遍发展阶段的刷怪类型、相对权重、每组数量及解锁条件，沿用维度、水中／空中／地面、光照和碰撞检查。寄生虫使用独立的 csrp_parasite 刷怪类别，不受原版怪物全局上限和玩家附近上限约束，也不占用原版怪物名额。实际刷怪数量仍受模组自身数量上限和可用位置限制，不保证翻倍。

新配置使用新默认值。已有配置保留原值；退出游戏或服务器后，在 config/csrp-world.toml 中设置以下值并重启：

    worldSpawningMobCap = 100
    worldMobCapPlusPlayer = 20
    naturalSpawnWeightMultiplier = 6.0

保留模组数量上限与超量清理功能；召唤、增援和刷怪蛋不受权重调整影响。doMobSpawning、和平难度、距离、阶段、维度、光照和碰撞等正常刷怪条件仍然生效。

独立类别不再与原版怪物竞争刷怪权重；naturalSpawnWeightMultiplier 仍用于模组候选表，但同倍率缩放不会改变模组生物之间的相对权重。
