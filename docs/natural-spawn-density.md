# 自然刷怪数量调整

默认寄生虫刷怪权重从 3.0 提高到 6.0；维度内数量上限从 50＋每名玩家 10 提高到 100＋每名玩家 20（单人由 60 提高到 120）。

保留原有进化阶段与普遍发展阶段的刷怪类型、相对权重、每组数量及解锁条件，沿用维度、水中／空中／地面、光照和碰撞检查。实际刷怪数量仍受原版怪物上限和可用位置限制，不保证翻倍。

新配置使用新默认值。已有配置保留原值；退出游戏或服务器后，在 config/csrp-world.toml 中设置以下值并重启：

    worldSpawningMobCap = 100
    worldMobCapPlusPlayer = 20
    naturalSpawnWeightMultiplier = 6.0

保留数量上限与超量清理功能；召唤、增援和刷怪蛋不受权重调整影响。
